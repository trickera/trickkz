# trickkz — Patrick Ferreira · DevOps &amp; Cloud Engineer

Personal portfolio. Static site (HTML / CSS / vanilla JS, **no framework, no build step**), bilingual **PT/EN**, dark "ops console" terminal UI.

**Live:** https://trickkz.pages.dev · https://trickkz.com

## Highlights
- Vanilla HTML/CSS/JS — no framework, no build
- Bilingual PT/EN toggle, accent-color switch (green/amber)
- Self-hosted fonts (IBM Plex Sans · JetBrains Mono · Share Tech Mono) — zero third-party requests
- Interactive terminal, `man`-page modals, Kuchizu-style ambient HUD
- Deployed on Cloudflare Pages with a strict CSP and security headers (`_headers`)

## Run locally
Just open `index.html` in a browser. No build, no dependencies.

See [`DEPLOY.md`](DEPLOY.md) — Cloudflare Pages via a clean, minified `dist/`.
